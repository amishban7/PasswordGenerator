# Password Generator

A simple, user-friendly web application that generates random passwords with customizable options. Built to practice JavaScript logic, DOM manipulation, and interactive web development.

🔗 **Live Demo:** https://passwordgenerator55254.netlify.app/

## Features

* Generate random passwords instantly
* Customize password length
* Include uppercase and lowercase letters
* Include numbers and special characters
* Copy generated passwords to the clipboard
* Simple and responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone [https://passwordgenerator55254.netlify.app/]
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or run it using the Live Server extension.

## How It Works

The application uses JavaScript to select characters based on the user's preferences and generate a password of the requested length. The interface updates dynamically when the user changes the settings or generates a new password.
